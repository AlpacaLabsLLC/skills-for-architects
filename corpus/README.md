# Knowledge navigation

[Source catalog](sources/catalog.json) owns external identities and links; [jurisdictions](jurisdictions/catalog.json) owns the country → state/region → municipality hierarchy. A null source jurisdiction is shared/nongeographic. Filter topic and geography without asserting adoption or legal precedence. The catalog carries no source content. See [the source contract](../docs/source-integration-contracts.md).

The [component registry](components.json) maps maintained owners. Governance catalogs colocated here, including [host contracts](host-contracts.json) and [geographic applicability](geographic-applicability.json), are governance assets, not external knowledge. User evidence and records stay in the user's workspace.
