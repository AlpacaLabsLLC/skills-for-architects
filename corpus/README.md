# Knowledge

Original definitions and sourced methods live here alongside external-source
metadata. The [component registry](components.json) is the shared ownership map.
The [professional-practice corpus](practice-methods/us-professional-practice/README.md)
retains its existing concept IDs, source records and rights boundaries.

Source/jurisdiction manifests and externally referenced standards have their own
registries. A source link is not retrieved text or project-specific applicability.
Firm Standards/References and project records remain in the user's Studio.
