# Transparency

Make claims traceable. Show the inputs, units, formula and rounding behind derived values; keep material supporting data accessible in the requested output. Explain recommendations and distinguish accepted requirements, sourced facts, proposed design assumptions and unresolved choices.

External facts need the actual original URL or a precise authorized-document locator, publisher/title, relevant section/page and version/date. A source-manifest entry is a route, not retrieved evidence. The repository bundles no external tables, findings or source summaries. A dated task snapshot stays outside the plugin and is not automatically current authority.

Report source/data dates separately from retrieval dates, and disclose mismatched geography, editions, inaccessible sources or stale evidence. Do not infer an endpoint's refresh schedule from plugin prose. A parser receipt, arithmetic check, host inspection and independent review prove different things; follow the [completion contract](../docs/completion-reporting.md).
