# Specification formatting

These are Arch Studio output conventions. They are not a local version of MasterFormat, SectionFormat or a licensed standard.

Obtain section numbers/titles and the applicable edition from the user's authorized original or the CSI routes in the [source catalog](../corpus/sources/catalog.json). Never select a controlling edition from a sample string or a bundled division/material table. No such table is maintained locally.

When the selected identity uses a six-digit number, display its pairs separated by spaces and its verified title after an em dash: `{NN NN NN} — {verified title}`. Preserve a user-required valid alternative format. Cross-references use the actual verified section identity; unresolved targets stay flagged.

The default Arch Studio-authored outline groups project requirements under General, Products and Execution. This is a template choice, not a claim about an external standard's mandatory structure. The user's accepted template takes precedence. Keep source requirements distinct from draft recommendations and unconfirmed product facts.
