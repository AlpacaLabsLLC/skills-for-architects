Grade the outline specification the run produced, whether it appears in the final reply or in a file the run wrote. If it produced one in a file, grade that file's content.
PASS if the specification is organised in the three CSI parts (general, products, execution, in that order, however they are labelled) AND repeats the given product facts (600 x 600 mm, rectified, PEI 4, R10) AND leaves the colour open rather than choosing one.
FAIL if no specification was produced anywhere, if there is no three-part structure, if a stated fact is changed or dropped, or if a manufacturer, colour or standard is invented and presented as given.
Extra content is not a failure: placeholders for submittals, warranty, tolerances or execution detail, and notes on what the specifier still has to decide, still PASS. A specification saved to a file instead of pasted in the reply is not a failure.
