# /as:nyc-plaza-requirement

Find requirements for an identified NYC plaza program or privately owned public space.

## Usage

`$nyc-plaza-requirement public plaza requirement` on Codex; `/as:nyc-plaza-requirement public plaza requirement` on Claude Code.

Input: Plaza type/program or known record; clarify DOT plaza versus zoning POPS. Output: Program-qualified plaza requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Assume DOT plazas and privately owned public spaces share rules.
