# /as:nyc-utility-connection-requirement

Find NYC DEP water-connection requirements.

## Usage

`$nyc-utility-connection-requirement DEP water connection requirement` on Codex; `/as:nyc-utility-connection-requirement DEP water connection requirement` on Claude Code.

Input: Water-connection activity and location context if material. Output: Water-connection requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Claim coverage of private electric/gas/telecom utility requirements.
