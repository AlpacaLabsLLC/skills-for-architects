# /as:nyc-emissions-limit

Look up a published NYC building-emissions limit for an identified reporting period and category.

## Usage

`$nyc-emissions-limit LL97 emissions limit` on Codex; `/as:nyc-emissions-limit LL97 emissions limit` on Claude Code.

Input: Reporting period and legally identified category; unknowns stay unknown. Output: Emissions-limit citation, unit and period. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Calculate annual emissions, penalties or LL97 applicability.
