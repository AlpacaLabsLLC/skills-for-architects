# /as:nyc-fdny-rule

Find a named or numbered FDNY rule.

## Usage

`$nyc-fdny-rule FDNY rule text` on Codex; `/as:nyc-fdny-rule FDNY rule text` on Claude Code.

Input: Rule number/title or bounded FDNY subject. Output: FDNY rule evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Retrieve Fire Code text when no rule is requested.
