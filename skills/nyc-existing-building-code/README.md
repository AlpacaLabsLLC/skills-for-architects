# /as:nyc-existing-building-code

Find an NYC Existing Building Code provision or its publication/effective-date evidence.

## Usage

`$nyc-existing-building-code existing-building code text` on Codex; `/as:nyc-existing-building-code existing-building code text` on Claude Code.

Input: Edition and section/topic; filing/work dates only for applicability. Output: Existing-building provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Assume an enacted future code already applies; decide conversion compliance.
