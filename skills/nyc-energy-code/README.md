# /as:nyc-energy-code

Find NYC Energy Conservation Code provisions and documented pathway references.

## Usage

`$nyc-energy-code energy-code section` on Codex; `/as:nyc-energy-code energy-code section` on Claude Code.

Input: Edition, commercial/residential regime when material, section/topic. Output: Energy Code provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Calculate U-values, certify energy compliance, or assume ASHRAE edition.
