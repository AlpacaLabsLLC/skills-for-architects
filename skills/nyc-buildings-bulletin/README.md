# /as:nyc-buildings-bulletin

Find an identified DOB Buildings Bulletin.

## Usage

`$nyc-buildings-bulletin Buildings Bulletin number` on Codex; `/as:nyc-buildings-bulletin Buildings Bulletin number` on Claude Code.

Input: Bulletin number/year or unambiguous subject. Output: Buildings Bulletin evidence and document classification. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Treat a bulletin as code text or infer universal applicability.
