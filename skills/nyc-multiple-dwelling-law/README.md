# /as:nyc-multiple-dwelling-law

Find a New York State Multiple Dwelling Law provision relevant to a NYC inquiry.

## Usage

`$nyc-multiple-dwelling-law Multiple Dwelling Law section` on Codex; `/as:nyc-multiple-dwelling-law Multiple Dwelling Law section` on Claude Code.

Input: Section or bounded MDL topic; building facts only if applicability is requested. Output: State-owned MDL provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Assume MDL and NYC Housing Maintenance Code are interchangeable.
