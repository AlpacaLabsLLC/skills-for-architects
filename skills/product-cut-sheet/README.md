# Product cut sheet

Produce one tag-named FF&E specification sheet using an accepted template, explicit audience fields and revision-pinned product evidence. The host prepares data under the native [output contract](../../tools/renderers/ffe-output-contract.md), renders and visually inspects the actual PDF, and verifies the saved artifact with its own available tools; no Arch Studio runner or package is required.

Use `$product-cut-sheet` on Codex or `/as:product-cut-sheet` on Claude Code. For a complete set, use `/as:spec-book`. See [output contracts](../../tools/renderers/README.md).
