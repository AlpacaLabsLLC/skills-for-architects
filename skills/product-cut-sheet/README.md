# Product cut sheet

Create a source-faithful single-product FF&E cut sheet or spec book entry from a supplied PDF or product URL. Preserve selected identity and source limits; use ffe-spec-book for a complete FF&E book and spec-writer for Project Manual requirements.

Use `$product-cut-sheet` on Codex or `/as:product-cut-sheet` on Claude Code. For a complete set, use `/as:ffe-spec-book`. See [output contracts](../../tools/renderers/README.md).
