# Product cut sheet

Produce one tag-named FF&E specification sheet using an accepted template, explicit audience fields and revision-pinned product evidence. The host renders and visually inspects the actual PDF; the shared helper prepares data and verifies the saved artifact.

Use `$product-cut-sheet` on Codex or `/as:product-cut-sheet` on Claude Code. For a complete set, use `/as:spec-book`. See [output contracts](../../tools/renderers/README.md).
