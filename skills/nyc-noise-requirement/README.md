# /as:nyc-noise-requirement

Find NYC noise-control requirements for a bounded activity or source.

## Usage

`$nyc-noise-requirement noise-code requirement` on Codex; `/as:nyc-noise-requirement noise-code requirement` on Claude Code.

Input: Activity/source and section if known. Output: Noise requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Predict sound levels or certify an acoustic design.
