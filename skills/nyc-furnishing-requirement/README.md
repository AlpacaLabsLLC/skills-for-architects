# /as:nyc-furnishing-requirement

Find NYC requirements for furnishings in an identified use context.

## Usage

`$nyc-furnishing-requirement furniture or furnishing fire requirement` on Codex; `/as:nyc-furnishing-requirement furniture or furnishing fire requirement` on Claude Code.

Input: Furnishing type, occupancy and use location if known. Output: Furnishing requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Treat upholstery automatically as wall finish or approve a product.
