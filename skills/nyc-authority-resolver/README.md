# /as:nyc-authority-resolver

Identify candidate NYC authorities for one stated regulatory issue.

## Usage

`$nyc-authority-resolver which NYC agency regulates this` on Codex; `/as:nyc-authority-resolver which NYC agency regulates this` on Claude Code.

Input: Location and issue/activity. Output: Candidate-authority map with triggers and unknowns. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Infer legal precedence from folder hierarchy or provide a final compliance answer.
