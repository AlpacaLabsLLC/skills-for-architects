# /as:rhino-axon

The view for an axonometric sheet from a Rhino 9 model: camera and projection, exclusions and cut-away crop (drawn in outline; only details hatch cut faces), hidden-line occlusion, joint and detail-cut selection, and the building lock. It hands linework to [rhino-thinline](../rhino-thinline/README.md).
