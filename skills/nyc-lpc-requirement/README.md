# /as:nyc-lpc-requirement

Find an LPC rule or work-review requirement.

## Usage

`$nyc-lpc-requirement LPC rule or alteration requirement` on Codex; `/as:nyc-lpc-requirement LPC rule or alteration requirement` on Claude Code.

Input: Rule/work type; designation evidence if applicability requested. Output: LPC requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Determine landmark designation or promise approval.
