# /as:nyc-building-code

Find an identified NYC Building Code provision or narrowly named building requirement.

## Usage

`$nyc-building-code building-code section or provision` on Codex; `/as:nyc-building-code building-code section or provision` on Claude Code.

Input: Code edition and section/topic. Output: Building-code provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Calculate occupant load; select a code year; approve a building.
