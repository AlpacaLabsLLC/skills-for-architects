# studio

See [the skill](SKILL.md) and the canonical [workspace model](../../docs/workspace-model.md) for current operations and record ownership.

Fresh setup walks through four decisions in order: governance, practice areas, memory and tooling, then shows one preview for approval. Each step can take its defaults; the tools-only path writes nothing. Practice areas are recorded in STUDIO.md as advisory and never block a skill.

Studio setup offers an existing AI-use policy, the reviewable default, or decline under the [policy reference contract](../../docs/studio-policy.md). The existing setup preview covers the selected policy and manifest changes. Ordinary work preserves that choice.
