# /as:nyc-amendment-check

Find evidenced amendments affecting a bounded NYC provision and time interval.

## Usage

`$nyc-amendment-check what amended this section` on Codex; `/as:nyc-amendment-check what amended this section` on Claude Code.

Input: Base source/edition/provision and date interval. Output: Bounded amendment evidence and search limitations. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Claim an exhaustive legal history or treat every bulletin as an amendment.
