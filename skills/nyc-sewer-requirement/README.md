# /as:nyc-sewer-requirement

Find NYC sewer or wastewater connection requirements.

## Usage

`$nyc-sewer-requirement sewer connection rule` on Codex; `/as:nyc-sewer-requirement sewer connection rule` on Claude Code.

Input: Sewer/wastewater activity and location context if material. Output: Sewer requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Design drainage or approve connection capacity.
