# /as:nyc-zoning-provision

Retrieve an identified NYC Zoning Resolution provision.

## Usage

`$nyc-zoning-provision zoning section text` on Codex; `/as:nyc-zoning-provision zoning section text` on Claude Code.

Input: Section identifier or tightly bounded zoning topic; version/date if supplied. Output: Zoning provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Calculate buildable capacity, massing or decide variance eligibility.
