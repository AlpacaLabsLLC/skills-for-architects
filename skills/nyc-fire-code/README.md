# /as:nyc-fire-code

Find an identified NYC Fire Code provision.

## Usage

`$nyc-fire-code fire-code section` on Codex; `/as:nyc-fire-code fire-code section` on Claude Code.

Input: Edition and section or fire-safety topic. Output: Fire Code provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Treat a Building Code provision as an FDNY operational approval.
