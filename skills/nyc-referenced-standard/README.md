# /as:nyc-referenced-standard

Identify the standard and edition incorporated by an identified NYC provision.

## Usage

`$nyc-referenced-standard which ASTM NFPA UL ASHRAE edition is referenced` on Codex; `/as:nyc-referenced-standard which ASTM NFPA UL ASHRAE edition is referenced` on Claude Code.

Input: Controlling code source/edition/provision and standard designation if known. Output: Referenced-standard metadata and authorized access route. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Supply copyrighted standard text or assume the publisher newest edition is incorporated.
