# /as:nyc-street-tree-requirement

Find NYC Parks street-tree planting or work requirements.

## Usage

`$nyc-street-tree-requirement street-tree requirement` on Codex; `/as:nyc-street-tree-requirement street-tree requirement` on Claude Code.

Input: Planting/work activity and location context if material. Output: Street-tree requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Select species or approve tree removal.
