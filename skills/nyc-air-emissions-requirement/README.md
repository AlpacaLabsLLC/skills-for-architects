# /as:nyc-air-emissions-requirement

Find NYC air-emissions or air-permit requirements for identified equipment or activity.

## Usage

`$nyc-air-emissions-requirement air permit requirement` on Codex; `/as:nyc-air-emissions-requirement air permit requirement` on Claude Code.

Input: Equipment/activity and provision if known. Output: Air-emissions requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Calculate dispersion or decide permit eligibility.
