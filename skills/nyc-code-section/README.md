# /as:nyc-code-section

Retrieve a specifically identified NYC regulatory provision.

## Usage

`$nyc-code-section look up this exact code section` on Codex; `/as:nyc-code-section look up this exact code section` on Claude Code.

Input: Regime/edition and section identifier. Output: Identified provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Guess regime from a bare section number or perform code analysis.
