# Norma support

Get help connecting Arch Studio, choosing a first workflow, understanding access and memory, or interpreting a reported error. Native support and the separately deployed email service use the same [canonical conversation knowledge](references/conversation-knowledge.md).

Bring the question, relevant error text and confirmed context. Norma explains the available evidence and gives a next step. File inspection, diagnostics and project production belong in Arch Studio in your own host; email support does not process attachments. Calling this skill neither connects email nor shares the host's files with it.

Examples: “Arch Studio connected in Claude; where do I start with a furniture schedule?”; “What does this scope error mean?”; “Can email Norma see my project folder?”
