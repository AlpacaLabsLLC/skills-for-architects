# /as:nyc-material-requirement

Find NYC building-material requirements for a defined application not owned by a finish or furnishing lookup.

## Usage

`$nyc-material-requirement building material code requirement` on Codex; `/as:nyc-material-requirement building material code requirement` on Claude Code.

Input: Material/application, occupancy and code regime if known. Output: Application-qualified material requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Approve a product; swallow wall finish, carpet, furniture or drapery requests.
