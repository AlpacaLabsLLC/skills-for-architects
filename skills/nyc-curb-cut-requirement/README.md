# /as:nyc-curb-cut-requirement

Find NYC curb-cut requirements and documented agency review routes.

## Usage

`$nyc-curb-cut-requirement curb-cut requirement` on Codex; `/as:nyc-curb-cut-requirement curb-cut requirement` on Claude Code.

Input: Location/use and work type if material. Output: Curb-cut requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Approve driveway access or calculate zoning capacity.
