# /as:nyc-drapery-requirement

Find NYC requirements for curtains, drapery or decorative textiles.

## Usage

`$nyc-drapery-requirement curtain or drapery fire requirement` on Codex; `/as:nyc-drapery-requirement curtain or drapery fire requirement` on Claude Code.

Input: Hanging/decorative textile application, occupancy and location if known. Output: Drapery requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Treat a curtain as an interior wall finish or substitute upholstery testing.
