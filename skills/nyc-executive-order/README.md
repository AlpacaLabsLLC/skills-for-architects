# /as:nyc-executive-order

Find an identified NYC executive order.

## Usage

`$nyc-executive-order NYC executive order number` on Codex; `/as:nyc-executive-order NYC executive order number` on Claude Code.

Input: Order number/year or unambiguous title. Output: Executive-order evidence and scope unknowns. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Treat an order as a permanent amendment without evidence.
