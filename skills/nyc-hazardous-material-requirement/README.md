# /as:nyc-hazardous-material-requirement

Find a bounded NYC hazardous-material requirement while distinguishing DEP and FDNY responsibilities.

## Usage

`$nyc-hazardous-material-requirement hazardous-material storage or reporting requirement` on Codex; `/as:nyc-hazardous-material-requirement hazardous-material storage or reporting requirement` on Claude Code.

Input: Material, quantity if known and activity; do not infer classification. Output: Authority-qualified hazardous-material requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Give handling instructions, classify unknown chemicals or certify safety.
