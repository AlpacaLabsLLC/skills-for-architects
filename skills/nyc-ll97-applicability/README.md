# /as:nyc-ll97-applicability

Gather bounded Local Law 97 applicability evidence and unresolved screening facts.

## Usage

`$nyc-ll97-applicability does LL97 apply` on Codex; `/as:nyc-ll97-applicability does LL97 apply` on Claude Code.

Input: Building identifiers, floor-area evidence and relevant reporting year if known. Output: LL97 applicability evidence with unresolved conditions. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Certify exemption, calculate emissions or declare complete applicability.
