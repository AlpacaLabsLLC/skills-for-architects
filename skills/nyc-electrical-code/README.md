# /as:nyc-electrical-code

Find an NYC Electrical Code provision and its referenced-edition evidence.

## Usage

`$nyc-electrical-code electrical-code section` on Codex; `/as:nyc-electrical-code electrical-code section` on Claude Code.

Input: NYC edition and section or electrical topic. Output: Electrical provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Substitute an unamended NEC edition or design a circuit.
