# /as:nyc-code-note

Find a DOB Code Note for a bounded filing or work topic.

## Usage

`$nyc-code-note DOB Code Note` on Codex; `/as:nyc-code-note DOB Code Note` on Claude Code.

Input: Work topic or Code Note title. Output: Code Note guidance evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Treat guidance as enacted law or a project approval.
