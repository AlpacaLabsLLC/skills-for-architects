# Product image processor

Prepare sourced FF&E images from adopted item revisions, explicit one-off inputs or the optional CSV library. Preserve selected finishes and originals; record exact/representative/missing image status, processing parameters and hashes for downstream sheets.

Use `$product-image-processor` on Codex or `/as:product-image-processor` on Claude Code. Host image/download tools perform the operation; background removal runs only when requested. Image receipts do not mutate specification records. See [output contracts](../../tools/renderers/README.md) for revision-pinned sheet/package use.
