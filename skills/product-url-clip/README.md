# Product URL Clip

Captures one supplied product URL as sanitized, immutable project evidence and lists local capture
history without network retrieval. It never saves `product-library.csv` or adopts a schedule item.

Use `$product-url-clip` on Codex or `/as:product-url-clip` on Claude Code. See [SKILL.md](SKILL.md)
for the host-retrieval, idempotency, privacy and recovery boundaries.
