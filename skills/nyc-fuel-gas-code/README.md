# /as:nyc-fuel-gas-code

Find a provision in an identified NYC Fuel Gas Code edition.

## Usage

`$nyc-fuel-gas-code fuel-gas code section` on Codex; `/as:nyc-fuel-gas-code fuel-gas code section` on Claude Code.

Input: Edition and provision or fuel-gas topic. Output: Fuel-gas provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Size gas piping or approve equipment.
