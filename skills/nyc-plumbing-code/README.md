# /as:nyc-plumbing-code

Find a provision in an identified NYC Plumbing Code edition.

## Usage

`$nyc-plumbing-code plumbing-code section` on Codex; `/as:nyc-plumbing-code plumbing-code section` on Claude Code.

Input: Edition and provision or plumbing topic. Output: Plumbing provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Size a plumbing system or calculate fixture counts.
