# /as:ada-requirement

Find a federal ADA provision or technical requirement.

## Usage

`$ada-requirement ADA section or technical requirement` on Codex; `/as:ada-requirement ADA section or technical requirement` on Claude Code.

Input: ADA regime and section/element; jurisdiction only for separate local overlays. Output: Federal ADA provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Assume federal ADA resolves state/local accessibility or project applicability.
