# /as:nyc-stormwater-requirement

Find NYC stormwater requirements for a bounded project activity.

## Usage

`$nyc-stormwater-requirement stormwater requirement` on Codex; `/as:nyc-stormwater-requirement stormwater requirement` on Claude Code.

Input: Activity, discharge context and section if known. Output: Stormwater requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Size detention or claim a project is exempt.
