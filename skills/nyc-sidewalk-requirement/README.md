# /as:nyc-sidewalk-requirement

Find NYC sidewalk construction, maintenance or permit requirements.

## Usage

`$nyc-sidewalk-requirement sidewalk requirement` on Codex; `/as:nyc-sidewalk-requirement sidewalk requirement` on Claude Code.

Input: Work/activity and location context if material. Output: Sidewalk requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Design the sidewalk or determine street-tree obligations.
