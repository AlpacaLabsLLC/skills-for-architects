# /as:nyc-construction-administration

Find NYC construction administrative provisions, including Title 28 references.

## Usage

`$nyc-construction-administration construction administrative provision` on Codex; `/as:nyc-construction-administration construction administrative provision` on Claude Code.

Input: Title/chapter/section or bounded administrative topic. Output: Administrative provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Make a permit determination or replace DOB filing review.
