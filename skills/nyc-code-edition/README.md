# /as:nyc-code-edition

Find evidenced NYC code-edition candidates for one regime and project timeline.

## Usage

`$nyc-code-edition which NYC code edition applies` on Codex; `/as:nyc-code-edition which NYC code edition applies` on Claude Code.

Input: Regime; filing/work dates and existing-building facts if known. Output: Edition-candidate evidence with unresolved applicability. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Set one global NYC code year or choose newest by default.
