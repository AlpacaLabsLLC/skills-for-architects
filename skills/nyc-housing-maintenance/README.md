# /as:nyc-housing-maintenance

Find a NYC Housing Maintenance Code provision.

## Usage

`$nyc-housing-maintenance housing maintenance requirement` on Codex; `/as:nyc-housing-maintenance housing maintenance requirement` on Claude Code.

Input: Section or housing-maintenance topic. Output: Housing Maintenance Code provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Search address-specific HPD violations.
