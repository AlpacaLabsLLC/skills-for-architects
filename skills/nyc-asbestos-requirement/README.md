# /as:nyc-asbestos-requirement

Find NYC asbestos survey, filing or abatement requirements.

## Usage

`$nyc-asbestos-requirement asbestos requirement` on Codex; `/as:nyc-asbestos-requirement asbestos requirement` on Claude Code.

Input: Activity and provision/topic; work scope when material. Output: Asbestos procedural requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Provide abatement instructions or conclude material is asbestos-free.
