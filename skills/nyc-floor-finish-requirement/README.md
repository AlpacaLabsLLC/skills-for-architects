# /as:nyc-floor-finish-requirement

Find NYC requirements for floor finishes including carpet.

## Usage

`$nyc-floor-finish-requirement carpet or floor finish requirement` on Codex; `/as:nyc-floor-finish-requirement carpet or floor finish requirement` on Claude Code.

Input: Floor application, occupancy and location if known. Output: Floor-finish requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Apply wall/ceiling finish classification to flooring.
