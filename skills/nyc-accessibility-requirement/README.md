# /as:nyc-accessibility-requirement

Find NYC accessibility provisions with federal ADA obligations kept distinct.

## Usage

`$nyc-accessibility-requirement NYC accessibility requirement` on Codex; `/as:nyc-accessibility-requirement NYC accessibility requirement` on Claude Code.

Input: Element/use, NYC edition if known and requested regime. Output: NYC accessibility provision evidence with separate federal pointer. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Treat NYC approval as ADA compliance or design a compliant route.
