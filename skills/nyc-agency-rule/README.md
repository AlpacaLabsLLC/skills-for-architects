# /as:nyc-agency-rule

Find an identified NYC agency rule.

## Usage

`$nyc-agency-rule NYC agency rule text` on Codex; `/as:nyc-agency-rule NYC agency rule text` on Claude Code.

Input: Agency plus rule citation or unambiguous title. Output: Identified agency-rule evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Treat guidance or a proposed rule as an adopted rule.
