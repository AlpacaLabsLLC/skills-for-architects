# /as:nyc-mechanical-code

Find a provision in an identified NYC Mechanical Code edition.

## Usage

`$nyc-mechanical-code mechanical-code requirement` on Codex; `/as:nyc-mechanical-code mechanical-code requirement` on Claude Code.

Input: Edition and provision or mechanical topic. Output: Mechanical provision evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Design HVAC or calculate ventilation rates.
