# FF&E specification book

Assemble an ordered FF&E specification book from selected product cut sheets, with every product accounted for and verified package receipts. Use for grouped sheets or a combined FF&E book; use spec-writer for Project Manual sections.

Use `$ffe-spec-book` on Codex or `/as:ffe-spec-book` on Claude Code. Composes [product-cut-sheet](../product-cut-sheet/README.md); rendering and application access come from the host. See [output contracts](../../tools/renderers/README.md).
