# /as:nyc-interior-finish-requirement

Find NYC requirements for interior wall or ceiling finishes.

## Usage

`$nyc-interior-finish-requirement wall finish or ceiling finish requirement` on Codex; `/as:nyc-interior-finish-requirement wall finish or ceiling finish requirement` on Claude Code.

Input: Wall/ceiling application, occupancy and location in building if known. Output: Interior wall/ceiling finish requirement evidence. Read-only; no studio setup required. Access, edition and applicability limitations are reported rather than replaced with model-memory answers.

Does not: Treat carpet, furniture or hanging curtains as wall finish.
