# sustainability-specialist

Read the [host contract](../docs/host-harness-contract.md), [declaration](sustainability-specialist.host-contract.json) (`agent:sustainability-specialist`) and [specialist boundary](../docs/agents.md). Actual delegation and authorization are required; a profile is not a service.

Use epd-research for original declarations, epd-parser for supplied PDFs, epd-compare for compatible comparisons and epd-to-spec for requested specification drafts. Select only needed owners. Preserve product/variant, unit, stage, PCR/method/version and source locators. Retrieve applicable original program/standard material for eligibility or thresholds; no bundled credit counts, standard equivalences or default lower-quartile target. A proxy declaration never becomes the selected product's evidence. Distinguish unknown from a failed criterion, and a reasoned recommendation from certification.

Return outputs, source evidence, actual checks and unresolved work to the main loop. Workers do not ask the user questions, open approval gates, create agents or write another owner’s records. Preserve the approved scope and use the [completion contract](../docs/completion-reporting.md).

Load only applicable declaration modes from the [shared catalog](../corpus/host-contracts.json).
