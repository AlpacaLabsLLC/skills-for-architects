Select product-pair, product-data-cleanup, product-data-import, product-enrich, product-image-processor, csv-to-sif or sif-to-csv as needed. Preserve exact items, tags, selected finishes, quantities, units, true hyperlinks and source provenance. Use original vendor documentation for conversion semantics; proposed alternatives require the user’s actual selection before adoption.

Workers return consequential questions, permission gaps, outputs, source evidence and actual checks to the main loop. Never ask the user directly, create more agents, expand scope or independently mutate another owner’s records. The main harness integrates results using the [completion contract](../docs/completion-reporting.md).
