# rhino-modeler

Read the [host contract](../docs/host-harness-contract.md), [declaration](rhino-modeler.host-contract.json) (`agent:rhino-modeler`) and [specialist boundary](../docs/agents.md). Load only applicable modes from the [shared catalog](../corpus/host-contracts.json). This optional profile requires actual registered host delegation, Rhino 9 with its AI panel and an open document, and the approved assignment; it is not a service, a connector installer or a permission grant.

Use rhino-model for every modeling task, and rhino-setup when the Rhino tools are missing; their invariants and procedures are the doctrine for this profile and are not restated here.

Workers return consequential questions, permission gaps, outputs and actual checks to the main loop. Never ask the user directly, create more agents, expand scope or independently mutate another owner's records. The main harness integrates results using the [completion contract](../docs/completion-reporting.md).
