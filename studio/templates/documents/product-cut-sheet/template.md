# Product cut sheet template — 1.0.0

Reference the shared Arch Studio document design system and resolved page/grid/type parameters. Do not copy this layout into a skill. Default layout is original synthetic guidance; it never supersedes an explicitly accepted customer reference.

## Content mapping

| Region | Input | Requirement |
|---|---|---|
| Header | Studio/project identifiers, revision/date | Keep clear hierarchy and source-pinned revision |
| Identity band | Exact output tag, item location/quantity when known | Preserve tag and selected grouping; unknowns explicit |
| Product title | Product name/category, manufacturer, model, selected finish | Use only evidenced allowlisted fields |
| Image region | Selected exact/representative image or authorized placeholder | Preserve aspect ratio, display status label; disclose low effective PPI |
| Specifications/features | Allowlisted field labels and values | Label dimensions and units; preserve all required content |
| Footer | Source link, revision/date, page numbering | Actual usable links; no private-control paths in client output |

## Size-aware adaptation

Compact portrait: stacked identity/title, main image, then two-column label/value specification/features region where readable. Compact landscape: image and specification regions side-by-side with shared header/footer. Standard and board sizes: use the resolved wider grid, separate image and specification/features regions, and additional whitespace rather than scaling a compact sheet. Never add products merely because a larger page has room. Grouping remains explicit in the output scope.

Margins, typography, grid column count and gutter are resolved by the shared system. All declared presets support both orientations. Custom pages must meet the resolver's minimum content area and physical limits. Long content uses continuation pages with the same tag, repeated header and a continuation label. The host updates expected page counts before verification; required fields must not disappear. Product images are illustrative, not scale drawings.
