# Specification book template — 1.0.0

Reference the shared document design system and product-cut-sheet template. The host produces/assembles the book; AS provides no PDF renderer or merger.

The explicit job contract determines scope, grouping, ordering and whether cover/index front matter is requested. Default assembly contains ordered cut sheets only. When front matter is requested, declare the exact number of pages, a cover with project/title/revision/audience and an index listing each exact expected tag with its actual page destination. Reconcile index page numbers after content pagination. Do not infer approval from the cover's revision label.

Use the same resolved physical size/orientation for front matter and content unless an explicitly supported mixed-size contract is introduced later. All bundled page presets support portrait/landscape with grid/type adaptations from the shared system; do not resize existing PDFs to conceal size mismatches. Continuation pages count toward each item’s declared page count. Book front matter uses the resolved content grid and readable type, not enlarged compact pages.

The host merges actual cut sheets in expected order, preserves live source links, then reopens and inspects all pages. Preserve prior issued packages. A corrected item, changed template/design system, source or audience invalidates the affected output; recompute the book and index. Deliver only approved output artifacts, excluding private job controls and render inputs.
