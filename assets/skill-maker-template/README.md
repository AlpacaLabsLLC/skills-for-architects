# Transmittal example

A non-installable custom-skill example for recording confirmed outgoing delivery.
It uses the current document-register owner and firm path template; it sends no
messages and maintains no parallel folder/numbering convention.

Copy/adapt the example into the selected user-owned skill scope and rename
SKILL.example.md to SKILL.md. Retrieve the Arch Studio workspace and document
contracts through the host's connection and perform their operations with the
host's own tools; the skill must not depend on an installed runner or package.
